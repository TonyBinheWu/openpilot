# C3X / tizi 夜間低光害顯示模式

此功能僅提供給 C3X（device type: `tizi`）。

目標是在夜間行駛時減少 OLED 全畫面發光造成的不適。啟用後，沿用現有 `OnroadScreenOffTimer` 延遲；倒數完成後不再顯示道路相機與模型覆蓋，而是改為黑底，只保留必要 HUD 與警示。由於 C3X 為 OLED，大部分黑色像素可維持不發光，以降低整體亮度與光害。

- 僅 `tizi` / C3X 顯示此模式；`tici` / comma three、`mici` / C4 與其他硬體不顯示。
- 可在行駛中切換。
- 延遲沿用現有行駛中亮度延遲設定。
- 觸控會暫時恢復完整畫面並重新計時。
- 有警示時會恢復完整畫面並重新計時。
- 不更動模型、控制、Panda、CAN 或 safety。

> 注意：檔名保留 `TICI_...` 是為了避免既有連結失效；實際支援裝置已更正為 C3X / `tizi`。
